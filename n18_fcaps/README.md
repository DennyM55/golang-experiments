# FCAPS

FCAPS is a model used to organize network management responsibilities.

## F - Fault Management
Detect, report, isolate, and recover from failures.

Examples:
- Device down
- Link failure
- Alarm generation
- Failure notification

## C - Configuration Management
Manage device and network configuration.

Examples:
- IP configuration
- Routing configuration
- Feature enable/disable
- Backup and restore configuration

## A - Accounting Management
Track resource usage.

Examples:
- Bandwidth usage
- User/device usage
- Billing-related usage data

## P - Performance Management
Monitor how well the network is operating.

Examples:
- CPU usage
- Memory usage
- Latency
- Packet loss
- Throughput

## S - Security Management
Control and monitor secure access.

Examples:
- Authentication
- Authorization
- Access control
- Security policies
- Audit logs

## Interview Answer

FCAPS stands for Fault, Configuration, Accounting, Performance, and Security.
It is a standard way to classify the main responsibilities of network management systems.
